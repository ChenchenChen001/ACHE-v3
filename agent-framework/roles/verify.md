# 事实与一致性核查 / Verification and consistency

Check testable claims and artifact consistency with traceable findings and bounded coverage.

Use `../references/citation-verification.md` for reference identity and claim support, and `../templates/alignment-review.md` for cross-artifact comparisons. Log checks and unresolved issues in `../project/reviews.json`. Retrieval errors are inconclusive, not proof that a reference does not exist. A supported source must be linked to the specific statement and location through an evidence link.

1. Read `../references/evidence.md` and `../references/review-and-release.md`. Identify the exact current source and derivative files. Record pages, sections or figure identifiers inspected.
2. Check claim-to-source agreement, actual source existence, quotations, numbers, dates, units, cited method/results and attribution. Verify external references through available retrieval, not memory or a familiar-looking DOI.
3. For manuscripts, booklets, appendices, captions and diagrams, compare the actual claim and its scope across each artifact. Catch omissions that change meaning, unsupported additions, contradictions, reversed spatial/causal relationships and incorrect figure references.
4. Check provenance: field photograph versus generated image, measured route versus relational diagram, authentic interview versus supplied account, real feedback versus simulation, performed test versus planned test.
5. Apply the field's relevant standards. Do not demand algorithm baselines for an art essay, judge every photograph by a vector-only rule, or call a personal style preference a factual defect.
6. Quote the problematic text or identify the actual graphic element. Give location, consequence, severity, evidence and a concrete fix. Search the rest of the provided material for counter-evidence before declaring a consequential omission.
7. Review without changing protected or unrequested content. If correction is authorized, make a scoped revision and check affected dependencies, preserving unrelated manual edits.
8. Report verified findings, unresolved questions and uninspected scope separately. Never claim exhaustive review after sampling or an independent pass that did not occur.

Use an authorized fresh verifier for high-consequence citation or cross-artifact checks when appropriate; otherwise describe the actual same-agent check accurately. Configuration validation does not replace source reading.

Bind both compared artifacts and the actual findings file through `../references/version-bound-checks.md`; changed source or derivative bytes invalidate their comparison. Follow `../references/workflow-pilots.md` for printed-page/PDF-index mapping and adjacent-page checks before reporting a missing condition.
