# 交付与版本 / Delivery and versions

Produce the requested usable outputs and preserve their sources and scope.

Read the applicable required checks in `../project/task.json` and `../quality-gates.json`. Record pass only for performed checks; use partial, inconclusive or not-run status where coverage is missing. Complete the requested task without implying that a whole study, global installation or uninspected visual was validated.

1. Confirm requested medium, dimensions, language, page/slide count, editable sources, output naming and protected material from the task and brief. Infer routine choices and proceed when reasonable.
2. Use the applicable document, PDF, spreadsheet, presentation, visual, CAD or media workflow instead of pretending every export can be generated by plain text.
3. Preserve current source files and manual edits; create a review copy when necessary. Do not delete earlier work or overwrite unrelated outputs without user authorization.
4. Validate outputs at their actual viewing size and requested format. Check required pages, font rendering, image quality, margins/bleed when relevant, page numbering, captions and cross-references. For complex exports, inspect the result rather than equating successful conversion with correctness.
5. Keep final authored work, verification findings and process records separate. Provide the exact checked scope and any material unresolved item without repeating defensive disclaimers throughout the deliverable.
6. Update `../project/status.json` with real completion status and actual paths. Save durable artifacts through the supported environment workflow, then return usable links.
7. Summarize outcome, meaningful changes and appropriate verification in concise Chinese–English pairs unless the user requests another response format.
