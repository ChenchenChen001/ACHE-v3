## 加载 / Loading

Read the installed original for the deliverable language when it is accessible; otherwise read `anti-defensive-writing.zh.md` or `anti-defensive-writing.en.md` beside this file. These are preserved reference copies, not a new global installation. Never edit originals while configuring or using this framework. If a future user edit changes an original, read the current original and record the discrepancy rather than silently overwriting it with a snapshot.

## 适用范围 / Scope

Apply the user's principles during argument planning, drafting, translation, polishing, abstracts, conclusions, project statements, captions, and presentations. Build around the strongest contribution the materials actually support. Lead with a clear positive statement; avoid repetitive caveats, ritual modesty, process diaries, and imagined-reviewer rebuttals. Do not replace the user's policy with a generic polishing template.

## 冲突处理 / Conflict resolution

1. Follow explicit user scope, protected content, and authorized editing intensity.
2. Preserve factual accuracy, real results, causal direction, authorial meaning, and material evidence boundaries.
3. Apply anti-defensive narrative and language choices within those boundaries.
4. Apply domain-specific writing and output conventions afterward.

Move audit findings, unresolved provenance and repeated caveats into the verification report or appropriate methods/discussion location. Keep a necessary qualification where removing it would change what the sentence means. A supported factual comparison, a failed prototype, a sample count or an uncertainty statement is not automatically self-undermining. Do not fabricate results, call simulated feedback real, describe a proposal as validated, or omit a result that would materially reverse the stated conclusion.

## 正文与核查 / Prose and verification

Write clean authored text; keep editorial process markers out of final prose. Resolve unsupported claims through research, a narrower supported statement or removal from factual prose; preserve consequential open questions in a separate report. Do not introduce a disclaimer into every caption or paragraph. In critique and internal records, describe limitations directly so the user can make informed decisions. Do not let persuasive prose suppress a genuine verification finding.

## 双语 / Bilingual delivery

Pair Chinese and English when that is the requested format. Keep the same claim strength, uncertainty and provenance in both languages; translation must not turn association into causation, a proposal into a result, or a local finding into a universal claim.
